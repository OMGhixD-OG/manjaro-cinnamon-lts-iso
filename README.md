# Manjaro Cinnamon Edition (Community Spin)

A community-maintained spin of **Manjaro Cinnamon (Full Edition)** crafted with `manjaro-tools` to keep the Cinnamon desktop experience alive, familiar, and ready for everyday use on Manjaro.

> **Current Version:** `26.1.3`[cite: 4, 6]

> **Disclaimer:** This is an independent community edition spin—not an official release of Manjaro Linux or the Manjaro team.

## What's Included

* **Long-Term Support Kernel (`linux618`):** Built on an LTS kernel for steady day-to-day stability and longevity.
* **Firefox Preinstalled:** Ships with **Firefox** as the default browser in place of Vivaldi[cite: 6].
* **Multimedia Out of the Box:** Includes `ffmpeg` for broad audio and video format support[cite: 6].
* **Flatpak & Package Management Ready:** Includes `libpamac-flatpak-plugin` alongside Pamac so Flatpak support works smoothly out of the box[cite: 6].
* **Helpful Utilities:** Includes `fastfetch`, `vim`, and a `fast-mirrors` helper command (`/usr/local/bin/fast-mirrors`) to quickly refresh fast mirrors[cite: 6].

## Getting Started

1. Download the Cinnamon ISO (`26.1.3`) from the **Releases** section of this repository[cite: 4, 6].
2. Verify the download checksum (`sha256sum` or `md5sum`) before flashing.
3. Flash the ISO to a USB drive, boot into the live session, and launch the installer.
